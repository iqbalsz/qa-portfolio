# Arif Iqbal — QA Engineer & Test Automation Portfolio

Modern, minimal personal portfolio and resume website of **M. Arif Iqbal Hidayatullah**, Software Quality Assurance and Test Automation Engineer.

## 🚀 Live Demo & Preview
- Open `index.html` directly in any web browser.

## 🛠️ Tech Stack & Features
- **Frontend:** Semantic HTML5, Vanilla CSS (Variables, Flexbox, Grid, Light/Dark theme switching), JavaScript ES6+
- **PDF Resume Generator:** Python script (`resume/build_pdf.py`) with ReportLab for compiling single-page ATS-friendly resumes
- **Responsive & Accessible:** Fully mobile-optimized with custom animated navigation drawer and smooth scroll reveals

## 📁 Project Structure
```text
├── index.html                  # Main portfolio website
├── css/
│   └── style.css               # Core styling & dark/light theme variables
├── js/
│   └── main.js                 # Theme toggler, scroll interactions, mobile menu
├── images/                     # Project screenshots & profile assets
└── resume/
    ├── CV_MArifIqbalHidayatullah.pdf # Latest single-page ATS resume
    ├── CV M.Arif Iqbal_QA.pdf        # Generated single-page ATS resume
    ├── build_pdf.py                  # Python generator script for the PDF resume
    └── resume_template.html          # Printable HTML template
```
